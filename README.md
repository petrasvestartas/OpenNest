# OpenNest

[![Support me on Ko-fi](https://ko-fi.com/img/githubbutton_sm.svg)](https://ko-fi.com/petrasvestartas)

**2D polygonal nesting for Rhino / Grasshopper** — pack irregular parts onto sheets with minimal waste
(parts and sheets may have **holes**, parts can nest **inside** holes, and sheets can be **non‑rectangular**).
The nesting engines are **C++ implementations** for Rhino .NET user interface.

![Parts nested to fill a shape with OpenNest](docs/assets/screenshot05.png)
