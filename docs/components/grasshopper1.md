# Grasshopper 1

OpenNest's components run in **classic Grasshopper** (Rhino 6, 7 and 8). Each component has its own tutorial with a
downloadable example — see **Nesting** ([OpenNest2](opennest2.md), [OpenNest1](opennest1.md),
[OpenNestCollision](opennest_collision.md)), **Geometry & sheets**, and **Utilities** in the navigation.

The same components also run in [Grasshopper 2](grasshopper2.md) (the new Rhino 8 editor) — identical inputs,
outputs and behaviour.
