# OpenNest Python example

Uses **compas_nest** — the OpenNest nesting engines (NFP + collision) published on PyPI.

- **Windows:** double-click `run.bat` (needs Python 3.9+).
- **macOS / Linux:** `./run.command` (needs Python 3.9+).

The first run `pip install`s `compas_nest` + `compas_viewer`, then runs `main.py`.
The same script also runs in the Rhino 8 Script Editor (the `# r: compas_nest` line installs the package there).
