Limits and implications for the independent implementation

These files are obfuscated decompiler output with delegate proxies, repeated
recovered names and artificial control flow. They are evidence of shipped
behavior, not a buildable original project. The observations do not establish
all native search heuristics, undocumented parameter values, commercial preset
equivalence or runtime performance. The separate constructive solver is a new
implementation; there is no claim that it reproduces the original Ultra result.

The new native benchmark operates only on pre-offset solve geometry. That is
an explicit adapter convention, not evidence that original CNS uses that same
internal representation. Source geometry clearance and sheet margins must be
checked independently after native output. Quantized pair collision predicates
can differ from the original floating-point polygons at sub-grid distances.
The stock-boundary rounding counterexample (width 4.000004 on stock width 4,
scale 100000) was reproduced and independently rejected; the geometry owner
subsequently added original-double bounds and inward stock lattice limits.
That fix does not remove the need for independent pair/source validation.
