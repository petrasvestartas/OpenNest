# OpenNest Constructive reference archive

These historical ledgers are reference material, separate from maintained solver code and runtime inputs. Their original attribution, commercial names, addresses, paths, uncertainties, and observations remain unchanged. The files were moved from `src/nest_constructive_cpp/docs/`; [archive_receipt.json](archive_receipt.json) records their original paths and unchanged SHA256 hashes.

The former maintained documentation described the provenance as follows:

> This is a reconstruction guided by decompiled artifact evidence, not recovered original buildable source or a claim of identical Ultra results. The evidence ledgers distinguish observed behavior from implementation choices.

- [orchestration_evidence.txt](orchestration_evidence.txt): managed orchestration observations and limitations.
- [search_evidence.txt](search_evidence.txt): native strategy observations and independent implementation choices.
- [geometry_evidence.txt](geometry_evidence.txt): geometry observations, attribution, and limitations.
- [remaining_search_gaps.txt](remaining_search_gaps.txt): historical gaps and the scope of the observations.

The historical references identify NestFab artifacts where appropriate; this archive does not relabel them as OpenNest or change their provenance. Required third-party notices and original-source attribution must accompany any applicable distributed code. No original binary was moved or modified by this archive operation.
